# for EspoCRM extensions : ext-compose

**Compose PDF**: Similar to a "print-to-pdf" feature, but the template is fully processed and opened in an editable view. This allows you to make manual adjustments before generating the final PDF.

**Compose SMS**: Similar to the PDF feature, this allows you to draft and send SMS messages directly. (Requires the ext-smsProvider extension for EspoCRM).

**Note**: Neither PDFs nor SMS messages are stored in the database.
